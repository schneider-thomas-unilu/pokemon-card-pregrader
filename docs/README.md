# Project Documentation

This folder contains the planning and design documents for Pokémon Card PreGrader.

- `approach-comparison.md` — comparison of the candidate AI approaches
- `architecture.md` — initial system architecture
- `cost-estimate.md` — estimated AI cost per card analysis
- `decision-and-mvp-plan.md` — approach decision, limitations, switching criteria, and MVP task plan
- `submission-summary.md` — concise project submission overview

See the repository's main `README.md` for the project overview and experiment instructions.
